# Contributing

Thank you for contributing to Interview Simulator!

## How to contribute

- Fork the repository and create a feature branch.
- Keep changes small and focused.
- Add or update documentation when you add new functionality.
- Run the app locally before opening a pull request.

## Coding standards

- Use consistent formatting and indentation.
- Keep frontend and backend logic separate where possible.
- Add tests or specs for new behavior whenever practical.

## Pull request process

1. Open a pull request with a clear title and description.
2. Reference any related issue or feature request.
3. Ensure the build passes and there are no obvious errors.
4. Request review from a maintainer.
