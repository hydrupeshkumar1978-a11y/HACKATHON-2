# User Manual

## Overview

Interview Simulator is a web app that lets candidates practice interview questions with an AI-powered interviewer.

## Quick start

1. Install dependencies with `bun install`.
2. Start the application with `bun run src/server.ts`.
3. Open `http://localhost:3000` in your browser.
4. Paste a job description, upload your resume, choose a persona, and start the interview.

## Features

- Resume upload for PDF, DOCX, and TXT
- Light/dark theme toggle
- Text-to-speech playback
- Live AI question streaming
- Session persistence in local storage
- Review and export transcripts
